# Servux-Paper (v1.0)

Servux-Paper is a Paper plugin that implements the Servux protocol for MiniHUD clients on multiplayer servers. It provides server-side data for MiniHUD features that normally require a modded server.

Minecraft version: 1.21.11 (Paper)

Edits and Paper port by lyntermint.

## Features
- Structures data for MiniHUD structure overlays.
- HUD data for TPS, tick time, and mob caps.

## Install
- Put the plugin jar into the Paper server `plugins` folder.
- Restart the server.
- Use a MiniHUD client to view Servux data.

## Build
- Run `./gradlew build`.
